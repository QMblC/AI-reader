# AI-reader

Backend приложения для чтения литературы с помощью ИИ. Принимает выделенный фрагмент текста, окружающий контекст и сведения о книге, чтобы вернуть перевод и объяснение смысла фрагмента.

**Версия:** 1.0. **Стек:** Java 21, Spring Boot, Maven.

## Возможности

- `POST /api/v1/analyses` — анализ текста с ответом из полей `translation` и `explanation`.
- `GET /actuator/health` — проверка состояния приложения.
- Swagger UI — `/swagger-ui/index.html` после запуска приложения.
- Валидация входных данных и формата ответа модели.

Сейчас анализ возвращает фиксированную заглушку: внешняя LLM не подключена, системный промпт пустой. Подготовка промпта и обращение к модели выделены в отдельный логический модуль, чтобы подключать и заменять провайдеров без изменения контроллера.

Подробнее: [архитектура](docs/architecture.md) и [подключение LLM](docs/llm-adapters.md).
